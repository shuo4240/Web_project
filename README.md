# 全齡向程式學習與運算思維培養的平台開發
本平台目標為結合運算思維遊戲化以及程式學習實作環境的系統，使用者可透過結合任務的遊戲，培養運算思維的四大核心(問題拆解、尋找規律、抽象化、演算法設計)，達到寓教於樂的目的。
同時透過測驗與程式實際撰寫強化學習效果

### 使用工具

| 功能分類   | 工具 / 技術                           |
|------------|----------------------------------------|
| 前端       | HTML、CSS、JavaScript、Jinja、Chart.js |
| 後端       | Flask（Python 框架）、Python 語言       |
| API        | QuizAPI、Cohere、YouTube Data API v3   |
| 自動排程   | APScheduler                            |
| 資料庫     | SQLite                                  |
| 郵件發送   | Gmail                                   |


### 功能特色
-	融合劇情的任務式遊戲讓使用者加深了解運算思維四大要點。
-	以圖像式程式編輯工具Blockly，讓學習者能透過視覺化的方式學習程式語言的條件判斷、順序執行、迴圈等邏輯。
-	提供教師上傳教學影片，並結合QuizAPI出題。
-	系統運用AI以及Judge0 API為學生提供題目解析以及程式批改的建議輔助學習成果的評估。
-	整合Google Custom Search API作為爬蟲工具，自動搜尋相關主題文章或教學內容，作為補強與延伸閱讀。
-	提供錯題回顧系統，並以Chart.js視覺化學生的學習成果。
-	透過 APScheduler 工作流程管理，每日定時寄送學習成果報告與錯題整理至學生 Gmail。
